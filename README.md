## Hi, I'm Jake

I'm a data analyst in Charlotte, NC. On my own time I build data products and AI tools.

Some of what I've built:

- SportsGods.com, a sports-analytics web app on Supabase Postgres and Cloudflare Workers. Its AI analyst can only answer through 8 read-only lookups, and a fact-check layer caught every fabrication in a 70-answer test.
- [claude-panel](https://github.com/jakefitz5/claude-panel), an open-source review tool. It runs 4 to 6 expert reviewers in parallel plus a skeptic, then has a different model write the summary so the panel doesn't grade its own work.
- 15+ agent skills that run my daily work, from a morning data pipeline to deploy gates and health checks, plus one that turns a plain-English brief into an animated explainer video.

Most of my code lives in private repos. You'll find more about each project at [jakefitzgerald.com](https://jakefitzgerald.com), and I'm happy to walk through any of it.
